# 当前口袋方法的分类评估

本评估固定原940配体实例、554 PDB的成员、输入RNA、候选和排序，比较当前RNA-only40（α=2、β=0.25、内部最多40区域、最终最多5候选）与既有fpocketR定位核心。按实验方法、RNA长度、链数和分辨率重新汇总，不重新调参或生成候选。

## 分组定义

- 实验方法：X-ray、电镜、NMR；另列Solution NMR与Solid-state NMR。
- RNA总长度：实际输入结构中全部受支持RNA链的观测核苷酸数之和，分为≤50、51–100、101–200、201–500、501–1000、>1000 nt。它不是SEQRES全长、单链全长或口袋长度。另报告最长观测链长度和链数，避免多链结构与长单链混淆。
- 分辨率：≤2、(2,2.5]、(2.5,3]、(3,3.5]、(3.5,4]、(4,5]、>5 Å。X-ray与电镜分别列出，NMR记为无分辨率，沿用原评估的首模型，不进行NMR多构象汇总。
- 实验方法×RNA总长度：提供交叉分组，帮助判断方法组的组成差异。

每个完整分组轴均覆盖全部940实例，且轴内成员互斥。同一PDB中多个配体位点仍分别计数；不同表是同一总体的不同切面，不能跨表相加。空分组明确列出。

## 指标与比较

Top1/3/5定位命中要求相应排序前缀中至少一个中心到真实配体任一重原子的最小距离DCA≤4.5 Å。RNA接触覆盖命中要求至少一个候选裁剪区域覆盖≥80%的原生RNA接触原子。覆盖率和中心距离沿用既有统一裁剪规则，没有针对任一方法修改标签。

fpocketR的无候选实例继续计为失败；本总体有241个这类实例。距离中位数仅在有候选时可计算，CSV同时列出可计算距离的数量，避免与完整分母的命中率混淆。

每组同时给出实例等权命中率、PDB等权站点命中比例、方法间配对差异及95%区间。PDB等权指标先计算各PDB所含位点的命中比例，再对PDB求平均，不是“任意位点命中即整个PDB命中”。区间采用5000次完整RNA冗余组配对bootstrap，固定随机种子20261007；每次两方法使用相同重采样。分组使用原序列及HARIBOSS等价关系冗余组，不解释为生物学家族。

实例少于20、PDB少于10或RNA组少于2时在报告中标记。该数据已用于方法研发，区间是当前固定数据和配置下的条件性描述，不构成新的独立测试。实验方法、长度和分辨率互相关联，组间差异不证明因果关系；未进行多组比较校正。

总体Top1/3/5仍为我们314/565/652，fpocketR238/387/428，准确复现原报告。

当前优势集中在NMR与≤200 nt的RNA；>200 nt仍是两方法的主要困难组。74个NMR实例中73个RNA总长度≤50 nt，因此NMR高命中率也与该组短RNA占比有关，不能仅归因于实验方法。电镜仅比对照多命中1例，配对Top5差异区间跨零，不能宣称稳定领先。高长度区间样本较少。X-ray分辨率组的结果并非随分辨率单调变化，不据此推断分辨率本身造成性能差异。完整分辨率表、Top1/3/5、覆盖率、距离与区间见生成报告。

## 复现与文件

在仓库根目录运行：

```bash
python scripts/stratify_pockets.py
```

默认读取原`outputs/hariboss_pocket_geometry_v5/{comparison,summary,verification}.json`及`outputs/hariboss_pocket_resolution5_v5/{pocket_manifest,grouping}.json`，并核对当前配置与原五折选择设置一致。脚本逐一核对输入结构哈希和RNA观测序列，检查分组与原外层折一致，重算并验证排序前缀指标，核对总体统计准确复现原结果。

输出目录`outputs/hariboss_pocket_stratified_v5/`：

- `summary.md`：完整可读分组表。
- `summary.json`：统计、区间和每组实例成员。
- `metrics.csv`：两方法每组Top1/3/5指标、可计算距离数量和区间。
- `paired.csv`：配对差值、仅我们命中、仅对照命中、共同命中和共同漏检数量。
- `sample_metadata.csv`：每实例实验方法、分辨率、长度、链数与冗余组。
- `contract.json`、`verification.json`：输入、源码和结构哈希，以及总体复现验证。

使用`--output-dir`指定新目录；其余路径与bootstrap参数可显式指定。同一目录只接受完全相同的契约，输入或实现变化时直接报错，需指定新目录。fpocketR对照为原fpocket4.0.3定位核心，未改为完整PyMOL/ProDy包装流程。
