PocketSeekR

An RNA-only tool for identifying candidate small-molecule binding pockets through geometry and regional chemical support.

Identify pockets Instructions

Background

PocketSeekR searches probe-accessible spaces and grooves around RNA, evaluates aromatic-face and directional polar support across each region, and selects complementary candidate pockets.

Only RNA coordinates are used. No ligand input or trained checkpoint is required. Calculation runs on your device; your structure is not uploaded.

Instructions

  1. Select a structure. Supply a PDB file with RNA coordinates, or load the example. The first structural model is used, including for NMR ensembles. Ligands and non-RNA residues are excluded.
  2. Identify pockets. Calculation runs locally in the browser. The first run loads about 30 MB of static assets; loading time depends on your connection. A completed calculation returns up to five pockets.
  3. Inspect the results. Select a pocket in the table to highlight its context crop in the 3D viewer. Drag to rotate and scroll to zoom. Download the JSON report or PDB coordinates.

Supported residues: A, U, G, C, I, RA, RU, RG, RC, PSU and H2U. Hydrogen atoms are omitted. Direct mmCIF input is not supported. Use the Python CLI for files larger than 20 MB.

Context crops are RNA neighborhoods, not cavity boundaries. Candidate centers indicate possible binding regions; pocket identification does not perform ligand docking.
